# Parking — iOS client

Native SwiftUI client for the Parking Space Reservation System. 80 spaces open at 20:00 for
the next day; roughly a thousand users compete for them.

| | |
|---|---|
| Platform | iOS 17+, SwiftUI |
| Concurrency | async/await throughout, `-strict-concurrency=complete`, zero warnings |
| Dependencies | none — `URLSession`, `Security`, `LocalAuthentication` only |
| Project | generated by XcodeGen from `project.yml`; the `.xcodeproj` is not committed |

## Quick start

```bash
brew install xcodegen swiftlint
make project && make ci
```

The backend must be running for the app itself; tests do not need it. See
[`docs/runbook.md`](docs/runbook.md).
